협의체 안건 도출 에이전트 (연습용) 사용법
=========================================

이 프로그램이 하는 일
  1) 동향 자료(엑셀에서 열 수 있는 CSV 파일)를 점검하고, 이슈별로 점수를 매겨 '선별 후보'를 보여줍니다.
  2) 담당자가 이슈를 확정하면, 업무 규칙을 점검한 뒤 협의체 안건서(Word)를 만듭니다.
     규칙 위반(오류)이 있으면 파일을 만들지 않고 멈춥니다.

이 프로그램이 하지 않는 일 (연습용이라 뺐습니다)
  웹 검색, AI 호출, 인터넷 연결, 이메일 발송, 화면 프로그램, 예약 실행.
  폴더 안의 자료만 사용하며, 자료에 없는 사실은 만들지 않습니다.

설치·시작 방법 (처음 한 번)
  1) '안건도출_에이전트.zip'을 받아 바탕화면 등에 두고, 마우스 오른쪽 -> '압축 풀기'로 폴더째 풉니다.
  2) 풀어낸 폴더 안의 '실행.bat'을 더블클릭합니다.
  * 파일을 하나씩 골라 복사하면 안 됩니다. 업무 규칙, 연습 자료, Word 도구가 함께 있어야 실행됩니다.
    빠진 파일이 있으면 프로그램이 '[준비 필요] ... 파일이 없어 시작할 수 없습니다'라고 알려줍니다.

가장 쉬운 실행 방법 (더블클릭)
  Windows : 폴더 안의 '실행.bat'을 더블클릭
  Mac     : 폴더 안의 '실행.command'를 더블클릭 (처음 한 번은 터미널에서 chmod +x 실행.command 필요할 수 있음)
  화면의 안내에 따라 진행합니다.
    1) 수집 기간 확인(엔터: 그대로)  2) 동향 점검과 이슈 선별  3) 담당자가 이슈 확정(Y 또는 코드 입력)
    4) 안건서 생성 후 결과 폴더가 자동으로 열림
  * 선별 후보는 초안이라, 담당자가 확정하는 질문에서 반드시 멈춥니다.
  * 규칙 위반(오류)이 있으면 안건서를 만들지 않고 점검 결과 파일(메모장)을 엽니다.
  * 중복 실행 방지: 이미 실행 중이면(창이 두 개 열려 있거나 두 번 더블클릭한 경우) 두 번째 실행은
    '이미 에이전트가 실행 중입니다' 안내만 보이고 끝납니다. 결과 파일이 겹쳐 덮어써지는 것을 막기 위함입니다.
    실행이 끝나거나 창을 닫으면 잠금은 자동으로 풀립니다(강제 종료로 남은 잠금도 다음 실행 때 자동 정리).
    창이 없는데도 안내가 계속 나오면 폴더의 '.agent.lock' 파일(숨김 파일)을 지우고 다시 실행하세요.
  * 폴더를 옮길 때는 폴더 전체를 옮겨야 합니다(실행 파일만 따로 옮기면 동작하지 않음).
  * Windows에서 '보호됨' 경고가 뜨면 '추가 정보' -> '실행'을 누르세요.
  * 실행.bat은 일부러 영문(ASCII)으로만 작성했습니다. 한글이 들어간 배치 파일은 Windows 설정에 따라
    '라벨을 찾을 수 없습니다' 오류나 글자 깨짐이 생길 수 있기 때문입니다. 한글 안내 화면은 프로그램이 직접 보여줍니다.
    (Python이나 Node.js가 없을 때만 영문 안내가 나옵니다: 본 설명서의 '준비물'을 참고하세요.)
  * 그래도 오류가 나면 화면의 문구를 그대로 복사해서 알려주세요.

준비물
  Python 3.8 이상 (https://www.python.org/downloads/ , 설치 시 'Add python.exe to PATH' 체크)
  Node.js (https://nodejs.org/ , Word 파일 생성용)
  Word 생성 부품(node_modules 폴더)은 이미 폴더에 들어 있어 인터넷 없이 실행됩니다.

직접 명령으로 실행하는 방법 (참고)
  한 번에 진행  python3 agenda_agent.py run   (더블클릭과 같은 화면 안내 방식)
  1단계  python3 agenda_agent.py select --기간 2026-08-29 2026-09-29
         -> 결과/1_동향_점검결과.txt, 결과/2_이슈_선별_결과.csv
         -> 화면에 선별 후보가 나오고 여기서 멈춥니다. 담당자가 이슈를 확정합니다.
  2단계  python3 agenda_agent.py build --이슈 A,B,C
         -> 결과/안건서_날짜.docx, 결과/3_안건서_점검결과.txt

폴더 구성
  실행.bat            (Windows) 더블클릭 실행 파일
  실행.command        (Mac) 더블클릭 실행 파일
  agenda_agent.py     프로그램 본체(중복 실행 방지 포함)
  .agent.lock         실행 중일 때만 생기는 잠금 파일(자동 삭제, 숨김 파일)
  build_agenda.js     Word 파일 만드는 도구(프로그램이 자동으로 호출)
  node_modules/       Word 생성 부품(삭제하지 마세요)
  업무규칙.json        업무 규칙(금지 표현, 요약 문장 수, 선별 기준 등). 여기서 바꿀 수 있습니다.
  연습자료/            동향_자료.csv, 이슈_정의.json, 이슈_정의_점검시험용.json
  결과/               실행 결과가 저장되는 곳
  결과_점검시험/       점검 시험(일부러 실수를 넣은 자료) 결과

점검하는 업무 규칙
  요약 3문장 이내 / 금지 표현 / 제목 표현 / 본문 미확인 표시 / 문장 끝 마침표 /
  근거 번호 존재 / 자료에 없는 수치 / 논의사항 구성(쟁점·선택지·의견) / 회의 산출물 /
  향후 조치와 논의사항 1:1 / 담당·시기 임의 기재 금지 / 산·학·관 표기 / 안건 간 중복
